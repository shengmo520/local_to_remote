# 青竹计划

> 把长期目标拆成「关键结果」，再拆成一个个能勾选的「行动」，进度自动汇总，到点提醒。

纯本地应用：数据只存在你自己的手机上，不上传、不需要注册登录。配色走国风方向——宣纸底、竹青主色、宋体标题、竹节纹色条。

## 功能

- **三层拆解**：目标 → 关键结果 → 行动。勾掉一个行动，关键结果和目标的进度自动向上汇总
- **今日待办**：自动汇总今天到期、以及已经逾期的行动，可以直接勾掉
- **到点提醒**：使用系统闹钟 + 通知，应用关掉、手机锁屏也会响
- **进度统计**：平均完成率、近 7 天完成情况、目标进度排行
- **四套配色**：青山 / 靛紫 / 暖阳 / 靛青，每套都支持跟随系统深色模式
- **备份**：一键导出 / 导入 JSON 文件
- **自动更新**：电脑端发布新版本后，打开应用会提示，点一下即可更新，不用重装

## 安装到手机

手机浏览器打开（WiFi 或流量都行）：

```
https://cdn.jsdelivr.net/gh/shengmo520/qingzhu-plan@main/docs/
```

点「下载安装包」→ 按提示允许「安装未知应用」→ 覆盖安装即可。

- 系统要求：Android 8.0 及以上
- 覆盖安装不会丢失已有数据
- 装在手机上的应用已内置更新地址，以后有新版本会自动提示

## 目录结构

```
index.html              应用本体（单文件，HTML/CSS/JS 全内联，浏览器直接打开也能用）

docs/                   对公网发布的更新源（GitHub Pages / jsDelivr 就指向这里）
  update.json           版本清单
  index.html            应用页面（构建号已写入）
  qingzhu-2.apk         安装包（内置了更新地址）
  download.html         手机浏览器打开根地址看到的下载页

android/                安卓外壳工程
  src/                  Java 源码：WebView 外壳、后台提醒、自动更新
  res/                  图标、主题、字符串
  AndroidManifest.xml
  build.ps1             编译打包 APK
  publish.ps1           打包 + 生成本地更新源 update/
  publish-cloud.ps1     打包 + 发布到公网（GitHub + jsDelivr）
  serve.ps1             局域网更新服务（备用方案）

update/                 本地更新输出，配合 serve.ps1 用（未纳入版本库）
```

## 自己重新打包

依赖：JDK 17、Android build-tools 34、platform 的 android.jar。本项目不使用 Gradle，直接用 aapt2 + javac + d8 手动打包。

```powershell
# 只打包出 APK
.\android\build.ps1

# 打包 + 生成本地更新源（配合 serve.ps1 供同一 WiFi 下的手机更新）
.\android\publish.ps1

# 打包 + 发布到公网（手机在任何网络下都能收到更新）
.\android\publish-cloud.ps1 -Push
```

## 更新机制

1. `publish-cloud.ps1 -Push` 把新构建推到仓库的 `docs/` 目录，并主动刷新 jsDelivr 缓存
2. 应用每次打开、以及从后台回到前台时，会拉取 `docs/update.json` 比对构建号
3. 发现新版本就弹面板，两种更新方式：
   - **内容更新**：只替换页面文件，下载后自动重启界面生效——不用重装、数据不动
   - **整包更新**：当原生外壳（Java / 清单 / 图标）也有改动时，下载 APK 并调起系统安装器

每个内容版本在手机上都存成独立文件名（`index-<构建号>.html`），从根上避免 WebView 缓存旧页面。

## 说明

- 最低支持 Android 8.0（API 26）
- 申请的权限只有：通知、精确闹钟、开机自启重排提醒、网络（检查更新）、安装应用（整包更新）。没有定位、通讯录、存储卡读取这类权限
- 数据保存在应用私有目录的浏览器本地存储里，**卸载应用会一并清空**，建议定期用「设置 → 导出备份」
- 应用本体就是一个 `index.html`，浏览器直接打开也能用（只是没有后台提醒和自动更新，那两项依赖安卓外壳）
